# Структура документов

## Типы документов

Каждый документ относится к одному типу. Смешивать типы в одном документе запрещено.

Таблица 1 – Типы документов

| Тип | Отвечает на вопрос | Пример заголовка |
|---|---|---|
| Обзор | Что это и зачем? | Обзор досок |
| Инструкция | Как сделать? | Как создать проект |
| Справочник | Какие есть параметры? | Справочник конечных точек задач |
| Руководство | Как достичь результата с нуля? | Первый проект в TaskFlow за 10 минут |
| Устранение неполадок | Что делать, если не работает? | Ошибки авторизации в API |
| Заметки о выпуске | Что изменилось? | Версия 3.4 |

## Обязательные элементы документа

1. Заголовок первого уровня — один на документ.
2. Вводный абзац из одного-двух предложений: что читатель узнает или сделает.
3. Раздел «Перед началом работы» — для инструкций: права, версии, подготовка.
4. Основная часть.
5. Раздел «Что дальше» — ссылки на связанные документы (рекомендуется).

## Правила построения инструкции

- Одна инструкция описывает одну задачу.
- Шаги нумеруются; в одном шаге — одно действие.
- В процедуре не больше 10 шагов. Если шагов больше, разбейте задачу на части.
- Результат действия указывается после шага, если он не очевиден: «Откроется окно
  **Новая задача**».
- Условие ставится перед действием: «Если проект закрыт, нажмите **Открыть заново**».

## Заголовки

- Заголовки пишутся с прописной буквы, без точки в конце.
- Заголовок инструкции начинается с «Как ...» или с глагола в инфинитиве: «Настроить
  уведомления».
- Уровни заголовков не пропускаются: после H2 идёт H3, а не H4.
- Глубина вложенности — не более трёх уровней.
