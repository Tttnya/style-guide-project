# Терминология

## Правила работы с терминами

<!-- vale off -->

**Т1.** Обязательно. Используйте только термины из глоссария. Синонимы для одного понятия
запрещены: если выбран термин «задача», нельзя писать «тикет», «таск» или «карточка».

<!-- vale on -->

**Т2.** Обязательно. Новый термин добавляется в глоссарий в том же Pull Request, в котором
он впервые появляется в документации.

<!-- vale off -->

**Т3.** Рекомендуется. Если есть устоявшийся русский термин, используйте его вместо
англицизма: «запрос», а не «реквест»; «развёртывание», а не «деплой».

<!-- vale on -->

**Т4.** Допускается. Английский термин в скобках при первом упоминании, если он нужен для
поиска: «маркер доступа (access token)».

## Глоссарий

Таблица 1 – Глоссарий TaskFlow

<!-- vale off -->

| Термин | Определение | Не использовать |
|---|---|---|
| задача | Единица работы с исполнителем, сроком и статусом | тикет, таск, карточка |
| доска | Набор колонок со статусами, на котором отображаются задачи | борд, канбан |
| проект | Набор досок и участников с общими настройками доступа | воркспейс |
| участник | Пользователь, добавленный в проект | мембер, юзер |
| исполнитель | Участник, ответственный за выполнение задачи | ассайни, ответственный |
| маркер доступа | Строка, которая подтверждает право клиента вызывать API | токен (в тексте), ключ |
| конечная точка | Адрес и метод HTTP, по которым API принимает запрос | эндпоинт, ручка |
| веб-перехватчик | Уведомление, которое TaskFlow отправляет на внешний URL | вебхук, хук |
| развёртывание | Публикация новой версии сервиса или документации | деплой, выкатка |

## Написание названий

- Название продукта: TaskFlow — латиницей, без кавычек, не склоняется.
- Названия сторонних продуктов пишутся так, как их пишет производитель: GitHub, MkDocs,
  JavaScript.
