# Доступность текста

Доступная документация понятна людям с нарушениями зрения, когнитивными особенностями и
тем, кто читает не на родном языке. Правила раздела основаны на рекомендациях WCAG 2.2.

## Альтернативный текст

**Д1.** Обязательно. У каждого изображения есть альтернативный текст, который передаёт
смысл, а не внешний вид: `![Окно создания проекта с полем «Название»](...)`.

**Д2.** Обязательно. Декоративные изображения получают пустой альтернативный текст:
`![](...)`.

**Д3.** Рекомендуется. Схему сопровождает текстовое описание или список шагов, которые она
показывает.

## Ссылки и заголовки

**Д4.** Обязательно. Текст ссылки понятен вне контекста. Запрещены ссылки «здесь», «тут»,
«по ссылке».

**Д5.** Обязательно. Заголовки идут по порядку уровней: экранные дикторы используют их для
навигации.

## Цвет и указания на расположение

**Д6.** Обязательно. Информация не передаётся только цветом: вместо «нажмите зелёную
кнопку» пишите «нажмите **Сохранить**».

**Д7.** Обязательно. Контраст текста на снимках экрана и схемах — не ниже 4,5:1 для
обычного текста и 3:1 для крупного (критерий 1.4.3 WCAG 2.2).

**Д8.** Рекомендуется. Не опирайтесь только на расположение: вместо «кнопка справа» укажите
название элемента.

## Простой язык

**Д9.** Рекомендуется. Используйте частотные слова и короткие предложения. Уровень текста
инструкций — понятный выпускнику школы.

**Д10.** Обязательно. Таблицы используются только для табличных данных, не для вёрстки.
У таблицы есть строка заголовков.

## Видео и анимация

**Д11.** Обязательно. Видео сопровождается субтитрами и текстовой версией инструкции.
Анимации GIF не длиннее 5 секунд и не мигают чаще трёх раз в секунду.
