# Шаблоны

Раздел содержит шаблоны для основных типов документов. Скопируйте шаблон и замените
значения в угловых скобках.

## Шаблон инструкции

```markdown
# Как <сделать что-то>

<Одно-два предложения: что читатель сделает и зачем.>

## Перед началом работы

- <Необходимые права>
- <Необходимые данные или настройки>

## <Название задачи>

1. <Действие в повелительном наклонении>.
2. <Действие>.

   <Результат действия, если он не очевиден.>

3. <Действие>.

## Что дальше

- [<Связанный документ>](<путь>.md)
```

## Шаблон описания конечной точки API

```markdown
# <Назначение в инфинитиве>

<МЕТОД> /api/v1/<путь>

<Одно предложение о том, что делает запрос.>

## Параметры

| Параметр | Тип | Обязательный | Описание |
|---|---|---|---|
| `<имя>` | <тип> | Да/Нет | <описание> |

## Пример запроса

## Пример ответа

## Коды ответа
```

## Шаблон заметок о выпуске

```markdown
# Версия <X.Y>

<Дата выпуска>

## Новое

## Изменено

## Исправлено
```
