# Иллюстрации

## Когда нужна иллюстрация

- Снимок экрана добавляется, если без него читатель не найдёт элемент интерфейса. Снимок
  не заменяет текст шага.
- Схема добавляется для описания архитектуры, потоков данных и процессов.
- Не добавляйте иллюстрации для украшения.

## Требования к снимкам экрана

- Формат PNG, ширина — не более 1600 пикселей.
- На снимке — только нужная область окна, без панели задач и закладок браузера.
- Персональные сведения заменяются тестовыми: «Иван Петров», `user@example.com`.
- Выделение — прямоугольная рамка цвета `#E53935` толщиной 2 пикселя. Стрелки и текст на
  снимке не используются.
- Интерфейс на снимке — на русском языке, светлая тема.

## Схемы

- Схемы создаются в Mermaid прямо в Markdown-файле, чтобы их можно было редактировать и
  проверять в ревью.
- Подписи на схеме совпадают с терминами из глоссария.

## Подписи и имена файлов

- Под каждой иллюстрацией — подпись в одном предложении без точки в конце.
- Имена файлов иллюстраций: `раздел-объект-действие.png`, например
  `project-create-dialog.png`.
- Файлы хранятся в папке `docs/images/` рядом с разделом.
